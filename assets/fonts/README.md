Self-hosted webfonts from @fontsource-variable/manrope 5.3.0 and
@fontsource-variable/oswald 5.3.0. The font files are unchanged; their CSS
uses local relative paths. Both families include Latin and Cyrillic subsets.

Sources: https://fontsource.org/fonts/manrope and
https://fontsource.org/fonts/oswald

Original license texts: Manrope-LICENSE.txt and Oswald-LICENSE.txt.

Brand lettering uses self-hosted Caveat Variable (400–700),
downloaded unchanged from Google Fonts CSS2 on 2026-10-28. The family has
Latin, Latin-ext, Cyrillic and Cyrillic-ext WOFF2 subsets; browser requests
only the subsets used by rendered text. Local paths replace Google URLs.
Source: https://github.com/google/fonts/tree/main/ofl/caveat
License: Caveat-LICENSE.txt (SIL Open Font License 1.1).

Reading text, metadata, labels, forms, controls and product information use Manrope Variable; large editorial headings and brand navigation retain Caveat.
