# Action buttons and links

Use text labels for shop action buttons and category tiles. Do not add decorative arrow or chevron icons to CTAs, category links, company-page links, newsletter submission or authentication submit buttons.

Gallery and carousel navigation keeps its existing controls and keyboard/swipe behaviour, with visible “Назад / Далі” or “Prev / Next” labels instead of arrow icons. Quantity plus/minus, account/cart/wishlist icons, social logos and normal form-field affordances retain their functions.

The collection cover uses a large headline raised into the clear left portion of the photograph on desktop. Keep mobile text within the artwork, below the models’ faces, and check both Ukrainian and English at narrow widths.
